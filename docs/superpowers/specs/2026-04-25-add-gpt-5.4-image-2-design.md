# Design — Add `openai/gpt-5.4-image-2`

## Goal
Register the OpenAI GPT-5.4 image-2 model in cc-hub so it's usable via `cc-hub imagine --model openai/gpt-5.4-image-2`, and provide a prompt guide consumed by `cc-hub prompt get`.

## Scope
- `src/data/models.ts` — add base + edit entries.
- `~/.claude-hub/prompts/openai-gpt-54-image-2.md` — generated prompt guide.
- `README.md` and `.claude/skills/cc-hub/references/models.md` — keep image-model listings in sync (project rule).

## Out of scope
- New providers, new commands, new CLI flags.
- Tests: existing `tests/services/models.test.ts` only asserts non-empty registry; no changes needed.

## Architecture
Pure data addition. Two entries appended to the OpenAI block of the "Poyo image models" section:

```ts
{ id: "openai/gpt-5.4-image-2",      type: "image", providers: { poyo: "gpt-5.4-image-2" } },
{ id: "openai/gpt-5.4-image-2-edit", type: "image", providers: { poyo: "gpt-5.4-image-2-edit" } },
```

Mapping rationale: the Poyo provider currently uses 1:1 slug equivalence for OpenAI image models (`openai/gpt-image-1.5` → `gpt-image-1.5`). The user is the source of truth for the canonical id. If Poyo exposes a different upstream slug, only the `poyo:` value needs updating.

## Prompt guide
Generated via `/prompt-guide` skill with `--model openai/gpt-5.4-image-2`. Filename follows the convention used by every OpenAI guide in `~/.claude-hub/prompts/` (drop the dot in version numbers): `openai-gpt-54-image-2.md`.

## Edge cases
- Poyo may not yet expose `gpt-5.4-image-2` upstream — runtime call will surface a Poyo error with the unknown slug. No registry-level validation needed.
- Edit variant follows the dual-pattern of `gpt-image-1.5/-edit` and `gpt-4o-image/-edit`. `openai/z-image` is a counter-example with no edit, but its model class differs (single-shot generation only).

## Doc sync
Per project CLAUDE.md, README.md and the cc-hub skill reference must list every image model. Add both new ids to:

- `.claude/skills/cc-hub/references/models.md` — `## Image (cc-hub imagine)` block.
