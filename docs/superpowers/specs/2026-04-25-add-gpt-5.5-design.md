# Design — Add `openai/gpt-5.5`

## Goal
Register OpenAI GPT-5.5 in cc-hub so it's usable via `cc-hub ask --model openai/gpt-5.5`, `cc-hub copilot --model openai/gpt-5.5`, and `cc-hub codex --model openai/gpt-5.5`. Provide a prompt guide consumed by `cc-hub prompt get --model openai/gpt-5.5`.

## Scope
- `src/data/models.ts` — single text entry mirroring `openai/gpt-5.4`.
- `~/.claude-hub/prompts/openai-gpt-55.md` — block-based operator-style prompt guide.
- `README.md` and `.claude/skills/cc-hub/references/models.md` — sync default-model lines if relevant (gpt-5.5 is the new most-capable text model but **defaults stay `openai/gpt-5.4`** until usage validates promotion).

## Out of scope
- Promoting gpt-5.5 to default for any command (premature without observed usage).
- New providers, new commands, new CLI flags.
- Tests: `tests/services/models.test.ts` only checks non-empty registry; no changes required.

## Architecture
Pure data addition. One entry inserted at the top of the OpenAI text cluster (before `gpt-5.4`):

```ts
{
  id: "openai/gpt-5.5",
  type: "text",
  providers: {
    openrouter: "openai/gpt-5.5",
    copilot: "gpt-5.5",
    codex: "gpt-5.5",
  },
},
```

Mapping rationale: mirrors the gpt-5.4 entry (the immediate predecessor). All three providers expose OpenAI text models with the canonical slug; only the codex CLI strips the `openai/` prefix.

## Prompt guide
Filename: `openai-gpt-55.md` (drop the dot, per existing convention: `openai-gpt-54.md`, `openai-gpt-52.md`).

Style: **block-based operator** (mirrors `openai-gpt-54-image-2.md`), not identity-based. Per project memory feedback (2026-04-25), prompt guides must use the new operator style.

Content sourced from extrapolation of GPT-5 family progression (5.2 → 5.4 → 5.5) and the existing `openai-gpt-54.md` baseline. Highlights expected for a x.5 minor:
- Same Responses API surface, `developer` role, reasoning effort scale.
- Improved instruction adherence (less reliance on contradiction-audit prompts).
- Native compaction + tool search (carried over from 5.4).
- Likely a new "agentic depth" knob or extended context — leave generic if uncertain.

If `/prompt-guide` skill is used and reaches public OpenAI docs, prefer its output. Otherwise write a manual guide based on 5.4 with version-bump deltas.
