# cc-hub

## Command reference

Use the `/cc-hub` skill for the full command reference (all commands, options, models, usage examples). Invoke it whenever you need to use a cc-hub command.

This skill must be kept up to date whenever a command is added, modified, or removed.

## Sync documentation on change

When a command, option, or model is added, modified, or removed, **always** update both:

1. `README.md` — the user-facing documentation
2. `.claude/skills/cc-hub/SKILL.md` — the skill that describes how to use cc-hub
