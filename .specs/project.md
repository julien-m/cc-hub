## Vision

**What the project does:**
cc-hub is an all-in-one AI Swiss-army knife CLI. It centralizes AI agent execution logs (with daily digest to Telegram), exposes multi-model AI capabilities (LLM, image, video, audio, music), and provides Claude Code integration utilities (skills, commands, rules, agent management). Runs entirely locally with zero server — callable from any directory.

**The core problem it solves:**
When AI agents run autonomously, there's no single place to know what happened. Claude Code also can't natively call OpenRouter, generate images or videos. cc-hub is the local middleware that centralizes these capabilities and provides a single morning digest via Telegram.

**Success in 2 years looks like:**
cc-hub remains a personal developer tool — richer integrations, more AI providers, more Claude Code utilities. No SaaS, no multi-user. The developer starts each day with a clear Telegram digest of what their AI agents did overnight.
