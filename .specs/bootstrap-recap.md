## Project Vision

<!-- Anchor: Q1 — What are you building? -->

**What the project does:**
[OBSERVED] cc-hub is an all-in-one AI Swiss-army knife CLI. It centralizes AI agent execution logs (with daily digest to Telegram), exposes multi-model AI capabilities (LLM, image, video, audio, music), and provides Claude Code integration utilities (skills, commands, rules, agent management). Runs entirely locally with zero server — callable from any directory.

**The core problem it solves:**
[OBSERVED] When AI agents run autonomously, there's no single place to know what happened. And Claude Code can't natively call OpenRouter, generate images or videos. cc-hub is the local middleware that centralizes these capabilities and provides a single morning digest via Telegram.

**Success in 2 years looks like:**
[INFERRED] cc-hub remains a personal developer tool — richer integrations, more AI providers, more Claude Code utilities. No SaaS, no multi-user.
